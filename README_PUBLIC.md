# Arvilo V31

Portfolio builder untuk siswa SMK dengan 1.000 kombinasi template.

## Katalog
- 20 template unggulan ditampilkan paling depan.
- Katalog utama tetap memiliki 1.000 template.
- Hanya 20 template dirender per halaman.
- Search, filter, pagination, dan pemilihan template aktif untuk elemen dinamis.

## Interaksi
Semua tombol utama menggunakan event listener yang dibind langsung setelah elemen dibuat. Kartu template juga dapat dipilih dengan klik, Enter, atau Space.

Lihat PAYMENT_SETUP.md. Jangan pernah menaruh Midtrans Server Key di frontend.
